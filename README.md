# e-plantShopping: Paradise Nursery

A dynamic, interactive shopping cart application for an online plant shop called Paradise Nursery. Built with React and Redux Toolkit.

## Features
* Interactive landing page with a background image.
* Browse 18 unique houseplants categorized by type (Air Purifying, Succulents, Low Light).
* Add plants to the shopping cart (button dynamically disables after adding).
* Shopping Cart management: increase/decrease quantities, remove items.
* Dynamically calculates sub-totals and total costs.
* Global state management using Redux.
